<h2 id="why">Why Allocera Intelligence Exists</h2>
<p>Ad platforms report the costs they control: clicks, spend, and the leads their own tracking can see. The costs that decide whether a campaign makes money usually live somewhere else. Lead partners take payouts. Customers refund. Payments get charged back weeks later. Compliance and fulfillment cost money on every sale.</p>
<p>When those costs are missing, the cost per lead used to decide where the next dollar goes is wrong, and it&rsquo;s wrong in the flattering direction. At real spend levels, that isn&rsquo;t a rounding error. It&rsquo;s a budget problem that compounds every month. Allocera Intelligence exists to close that gap: to put the real number, per campaign, in front of the person deciding where the money goes. Our guide to <a href="https://alloceraintelligence.com/marketing-costs/">marketing costs</a> shows what gets left out and why.</p>

<h2 id="founder">The Founder: Nick Baum</h2>
<p>Nick Baum is the founder of Allocera Intelligence and the builder of the CDAI engine. His background is in performance marketing, paid acquisition, and full-funnel measurement: building GA4 and Google Tag Manager setups, running Google and Meta campaigns, and tracking conversions for live, revenue-generating businesses, including ones in regulated industries.</p>
<p>Working inside lead generation operations, he kept running into the same problem. The dashboards looked fine, the campaigns got scaled, and the money didn&rsquo;t show up where the reports said it would. CDAI is the tool he wanted and couldn&rsquo;t find.</p>

<h2 id="what">What Allocera Intelligence Builds</h2>
<p>The CDAI engine connects to the ad accounts, CRM, and other tools a business already uses. Meta, Google Ads, LinkedIn, HubSpot, and Salesforce connect in one click. Every night, for every campaign, it:</p>
<ul>
  <li><strong>Calculates real profit:</strong> the revenue each campaign actually closed, minus ad spend, fees, partner payouts, refunds, chargebacks, compliance costs, and any operating costs you add.</li>
  <li><strong>Makes one clear decision,</strong> such as scale, hold, cut, or pause, with the numbers and a confidence level behind it. You stay in control of every move.</li>
  <li><strong>Rechecks its own math</strong> and stops on bad data instead of making decisions from it.</li>
  <li><strong>Grades its past decisions</strong> once enough time has passed to judge them.</li>
</ul>
<p>It&rsquo;s built for businesses that run on leads and closed deals, where the gap between the dashboard and the bank account is widest. See <a href="https://alloceraintelligence.com/how-it-works/">how it works</a> step by step, or look at the <a href="https://alloceraintelligence.com/dashboard/">dashboard</a>.</p>

<h2 id="math">Math, Not Guesses</h2>
<p>There is a difference between a system that predicts and a system that calculates. CDAI&rsquo;s numbers and decisions are calculated from your real data: what you spent, what closed, and what it cost to get there. Every number traces back to its source, and every decision shows the numbers behind it.</p>
<div class="abt-grid">
  <div class="abt-card"><h3>A guess sounds like</h3><p>&ldquo;Based on patterns, this campaign looks profitable.&rdquo;</p></div>
  <div class="abt-card"><h3>A calculation sounds like</h3><p>&ldquo;After payouts, refunds, and fees, this campaign made this much. Here is the decision, and here is why.&rdquo;</p></div>
</div>
<p>That is also why CDAI grades itself. A calculation can be checked later against what actually happened, and our <a href="https://alloceraintelligence.com/30-day-retest-methodology/">30-day retest</a> explains how.</p>

<script>
(function () {
  var GA_ID = "G-29J4V3VQ7B";
  var PAGE = (location.pathname || "/").replace(/^\/|\/$/g, "") || "home";
  window.dataLayer = window.dataLayer || [];

  // Load GA4 only if the site doesn't already load it (never double-counts page views).
  var hasGtag = typeof window.gtag === "function";
  var hasTagScript = !!document.querySelector('script[src*="googletagmanager.com/gtag/js"], script[src*="googletagmanager.com/gtm.js"]');
  if (!hasGtag && !hasTagScript) {
    var s = document.createElement("script");
    s.async = true;
    s.src = "https://www.googletagmanager.com/gtag/js?id=" + GA_ID;
    document.head.appendChild(s);
    window.gtag = function () { window.dataLayer.push(arguments); };
    window.gtag("js", new Date());
    window.gtag("config", GA_ID);
  }

  // Pushes a Tag Manager event and sends the same GA4 event. No personal data is ever sent.
  function track(name, params) {
    params = params || {};
    params.page_slug = PAGE;
    var dl = { event: "cdai_" + name };
    for (var k in params) { if (Object.prototype.hasOwnProperty.call(params, k)) dl[k] = params[k]; }
    window.dataLayer.push(dl);
    if (typeof window.gtag === "function") window.gtag("event", name, params);
  }

  function sectionOf(el) {
    if (el.closest("nav")) return "nav";
    if (el.closest("footer")) return "footer";
    if (el.closest("[class$='-final']")) return "final_cta";
    var h = null, node = el;
    while (node && node !== document.body) {
      var prev = node.previousElementSibling;
      while (prev) { if (/^H2$/.test(prev.tagName) && prev.id) { h = prev.id; break; } prev = prev.previousElementSibling; }
      if (h) break;
      node = node.parentElement;
    }
    return h || "intro";
  }
  function label(el) { return (el.getAttribute("aria-label") || el.textContent || "").replace(/\s+/g, " ").trim().slice(0, 80); }

  // Every link and button click.
  document.addEventListener("click", function (e) {
    var el = e.target.closest && e.target.closest("a, button, summary");
    if (!el) return;
    if (el.tagName === "SUMMARY") { track("faq_open", { question: label(el) }); return; }
    var href = el.getAttribute("href") || "";
    var p = { link_text: label(el), link_url: href, section: sectionOf(el) };
    if (/cdai-portal\.vercel\.app\/signup/.test(href)) track("signup_click", p);
    else if (/cdai-portal\.vercel\.app/.test(href)) track("portal_click", p);
    else if (/\/pricing/.test(href)) track("pricing_click", p);
    else if (/contribution-margin-marketing/.test(href)) track("validation_report_click", p);
    else if (/^#/.test(href)) track("toc_click", p);
    else if (/^https?:\/\//.test(href) && href.indexOf(location.hostname) === -1) track("outbound_click", p);
    else if (href) track("internal_link_click", p);
    else track("button_click", p);
  }, true);

  // How far people read (25/50/75/100%), each once per visit.
  var marks = [25, 50, 75, 100], hit = {};
  function onScroll() {
    var doc = document.documentElement;
    var pct = Math.round(((window.scrollY || doc.scrollTop) + window.innerHeight) / doc.scrollHeight * 100);
    marks.forEach(function (m) { if (pct >= m && !hit[m]) { hit[m] = true; track("scroll_depth", { percent: m }); } });
  }
  window.addEventListener("scroll", onScroll, { passive: true });

  // Which sections people reach (each H2, once per visit).
  if ("IntersectionObserver" in window) {
    var seen = {};
    var io = new IntersectionObserver(function (entries) {
      entries.forEach(function (en) {
        var id = en.target.id;
        if (en.isIntersecting && id && !seen[id]) { seen[id] = true; track("section_view", { section: id }); io.unobserve(en.target); }
      });
    }, { threshold: 0.6 });
    document.querySelectorAll("h2[id]").forEach(function (h) { io.observe(h); });
  }
})();
