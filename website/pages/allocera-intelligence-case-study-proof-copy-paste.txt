  <div class="section-inner prose">
    <h2 class="section-title fade-up">What Data-Driven <em>Marketing Actually Needs</em></h2>
    <div class="rule fade-up"></div>
    <div class="fade-up"><p><a href="https://www.salesforce.com/marketing/data-driven-marketing/" target="_blank" rel="noopener">Salesforce</a> describes data-driven marketing as an approach that &ldquo;uses information from a variety of sources to gain insights into consumer behavior, preferences, and trends.&rdquo; <a href="https://www.coursera.org/articles/data-driven-marketing" target="_blank" rel="noopener">Coursera</a> puts it more directly: it &ldquo;uses customer behavior data to predict future actions.&rdquo;</p>
<p>Both definitions assume the data is right. In practice it often isn&rsquo;t: ad data goes stale, leads arrive in the CRM without the campaign that produced them, and cost data sits in systems no dashboard reads. A tool that still produces a confident number in those conditions isn&rsquo;t data-driven marketing. It&rsquo;s a guess with decimal places.</p>
<p>CDAI was built against that failure. Every night, before it makes a single decision, it checks whether the data is fresh, complete, and consistent. If it isn&rsquo;t, no decisions go out, and you&rsquo;re told what&rsquo;s missing.</p>

    <div class="rule fade-up"></div>

<p><strong>The problem:</strong> every one of the 276 leads listed its source as &ldquo;Contact Import.&rdquo; Not one was tied to the campaign that produced it.</p>

The useful output here was the gap itself: fix lead attribution, and campaign-level decisions become possible.     var href = el.getAttribute("href") || "";
    var p = { link_text: label(el), link_url: href, section: sectionOf(el) };
    if (/cdai-portal\.vercel\.app\/signup/.test(href)) track("signup_click", p);
    else if (/cdai-portal\.vercel\.app/.test(href)) track("portal_click", p);
    else if (/\/pricing/.test(href)) track("pricing_click", p);
    else if (/contribution-margin-marketing/.test(href)) track("validation_report_click", p);
    else if (/^#/.test(href)) track("toc_click", p);
    else if (/^https?:\/\//.test(href) && href.indexOf(location.hostname) === -1) track("outbound_click", p);
    else if (href) track("internal_link_click", p);
    else track("button_click", p);
  }, true);

  // How far people read (25/50/75/100%), each once per visit.
  var marks = [25, 50, 75, 100], hit = {};
  function onScroll() {
    var doc = document.documentElement;
    var pct = Math.round(((window.scrollY || doc.scrollTop) + window.innerHeight) / doc.scrollHeight * 100);
    marks.forEach(function (m) { if (pct >= m && !hit[m]) { hit[m] = true; track("scroll_depth", { percent: m }); } });
  }
  window.addEventListener("scroll", onScroll, { passive: true });

  // Which sections people reach (each H2, once per visit).
  if ("IntersectionObserver" in window) {
    var seen = {};
    var io = new IntersectionObserver(function (entries) {
      entries.forEach(function (en) {
        var id = en.target.id;
        if (en.isIntersecting && id && !seen[id]) { seen[id] = true; track("section_view", { section: id }); io.unobserve(en.target); }
      });
    }, { threshold: 0.6 });
    document.querySelectorAll("h2[id]").forEach(function (h) { io.observe(h); });
  }
})();
</script>
