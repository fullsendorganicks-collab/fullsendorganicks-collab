    <div class="faq-list">
      <details class="faq-item">
        <summary>What is CDAI, exactly?</summary>
        <div class="faq-answer">CDAI is a deterministic, rules-based directive engine &mdash; not a predictive model. It reconciles your ad spend, CRM, and revenue data into one true number per campaign (true cost, true margin), then automatically issues one of eight directives every night: SCALE, HOLD, CUT, PAUSE, QUARANTINE, RENEGOTIATE, INVESTIGATE, or FLAG. Same inputs always produce the same output &mdash; no guessing.</div>
      </details>
      <details class="faq-item">
        <summary>Who is CDAI for?</summary>
        <div class="faq-answer">Any business running paid ads and/or buying leads, with <strong>HubSpot or Salesforce</strong> as its CRM. One CRM and one ad is enough: CDAI will still show you your true cost per lead and true customer acquisition cost. The CRM matters because it's where a lead turns into revenue. Leads that only pass through a call-tracking or lead-buying platform, with no HubSpot or Salesforce record behind them, can't be tied back to what they earned.</div>
      </details>
      <details class="faq-item">
        <summary>How accurate is it, really?</summary>
        <div class="faq-answer">98.0% on SCALE, 95.2% on HOLD, and 100% math verification &mdash; every dollar checked twice against raw data, zero mismatches. PAUSE is 85.2% and FLAG is 70.9%. Validated on 1,352 scored decisions across 9 businesses in 7 industries, run in a controlled environment and checked against the production database. Every number is in the report, including the weaker ones. <a href="https://alloceraintelligence.com/home-sample/contribution-margin-marketing/">Read the full validation report &rarr;</a></div>
      </details>
      <details class="faq-item">
        <summary>Does CDAI automatically pause my ad spend?</summary>
        <div class="faq-answer">No &mdash; and that's by design. CDAI tells you exactly what's true and issues a directive; a human decides what to do with it. CUT and PAUSE directives are advisory today: CDAI won't silently touch your ad accounts. You keep the wheel.</div>
      </details>
      <details class="faq-item">
        <summary>How fast do I actually see results?</summary>
        <div class="faq-answer">Your account and dashboard are ready seconds after you pay. Connect each tool with a click or an API key, and your first directives arrive on CDAI's next nightly run. Each night it reads a rolling window matched to your sales cycle (30 days by default, longer for long-cycle industries). HOLD, FLAG, and QUARANTINE can fire from day one on spend and lead data alone. SCALE and CUT need at least one closed sale first, since margin is mathematically undefined without revenue &mdash; that's arithmetic, not a slow rollout.</div>
      </details>
      <details class="faq-item">
        <summary>What if my data is missing or wrong?</summary>
            <div class="faq-answer">CDAI checks before it decides. Every night it looks for stale or broken data feeds, campaigns with revenue but no recorded spend, and campaigns that don&rsquo;t exist in your ad platforms. Serious data problems stop that night&rsquo;s directives instead of letting bad data drive a call. Anything that doesn&rsquo;t add up gets a FLAG for a person to review. Revenue it can&rsquo;t tie to a campaign, like referrals or offline sales, is kept separate instead of guessed at. And it rechecks its own math against the raw numbers every night.</div>
          </details>
          <details class="faq-item">
            <summary>Is my customers&rsquo; data safe?</summary>
            <div class="faq-answer">CDAI is built to hold no consumer identity data. Names, emails, phone numbers, addresses, and similar fields are stripped before anything is stored. Emails are kept only as one-way hashes, used to match a sale to the lead that produced it. Payments run through Stripe.</div>

    return (el.getAttribute("aria-label") || el.textContent || "").replace(/\s+/g, " ").trim().slice(0, 80);
  }

  // Every button and link click (no personal data is ever sent).
  document.addEventListener("click", function (e) {
    var el = e.target.closest && e.target.closest("a, button");
    if (!el) return;
    var href = el.getAttribute("href") || "";
    var p = { link_text: label(el), link_url: href, section: sectionOf(el) };

    if (el.closest("#cdai-ask-trigger, #cdai-ask-trigger-mobile, #hero-ask-trigger")) { track("chat_open", p); return; }
    if (el.closest("#cdai-chat-chips")) { track("chat_suggestion_click", p); return; }
    if (el.id === "cdai-chat-send") { track("chat_message_sent", { section: "chat" }); return; }
    if (el.id === "cdai-chat-close") { track("chat_close", { section: "chat" }); return; }
    if (el.id === "calcSendCode") { track("calculator_code_requested", p); return; }
    if (el.id === "calcVerify") { track("calculator_code_verified", p); return; }
    if (el.id === "navToggle") { track("menu_open", p); return; }
    if (el.id === "formSubmit") return; // tracked on form submit below

    if (/cdai-portal\.vercel\.app\/signup/.test(href)) track("signup_click", p);
    else if (/cdai-portal\.vercel\.app/.test(href)) track("portal_click", p);
    else if (/\/pricing/.test(href)) track("pricing_click", p);
    else if (/^#/.test(href)) track("scroll_link_click", p);
    else if (/^mailto:/.test(href)) track("email_click", p);
    else if (/^tel:/.test(href)) track("phone_click", p);
    else track("button_click", p);
  }, true);

  // Chat: message sent with the Enter key.
  document.addEventListener("keydown", function (e) {
    if (e.key === "Enter" && !e.shiftKey && e.target && e.target.id === "cdai-chat-input" && e.target.value.trim()) {
      track("chat_message_sent", { section: "chat" });
    }
  }, true);

  // Free audit / contact form.
  var form = document.getElementById("intakeForm");
  if (form) {
    form.addEventListener("submit", function () { track("form_submit", { form_name: "free_audit_contact", section: "intake" }); }, true);
  }
  var ok = document.getElementById("formSuccess");
  if (ok && window.MutationObserver) {
    var sent = false;
    new MutationObserver(function () {
      if (!sent && ok.offsetParent !== null) { sent = true; track("generate_lead", { form_name: "free_audit_contact", section: "intake" }); }
    }).observe(ok, { attributes: true, attributeFilter: ["style", "class"] });
  }

  // Calculator: first time someone types a number.
  var calc = document.getElementById("calcPanel");
  if (calc) {
    var started = false;
    calc.addEventListener("input", function () {
      if (!started) { started = true; track("calculator_start", { section: "calculator" }); }
    }, true);
  }

  // Which sections people actually reach (each fires once per visit).
  if ("IntersectionObserver" in window) {
    var seen = {};
    var io = new IntersectionObserver(function (entries) {
      entries.forEach(function (en) {
        var id = en.target.id;
        if (en.isIntersecting && !seen[id]) { seen[id] = true; track("section_view", { section: id }); io.unobserve(en.target); }
      });
    }, { threshold: 0.4 });
    ["hero", "tools", "problem", "how", "capabilities", "calcPanel", "faq", "intake"].forEach(function (id) {
      var el = document.getElementById(id);
      if (el) io.observe(el);
    });
  }
})();
</script>
